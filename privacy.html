Privacy Policy

Last updated: 12 November 2026

This policy covers turalstylist, a private tool the owner uses to manage their own YouTube channels (see the home page).

Data the tool accesses

When the owner signs in with Google, the tool gets an OAuth token. With it, the tool can read and update metadata for videos on the owner's own channel and read that channel's analytics. The data used is:

  • video titles, descriptions, tags, captions and schedule settings;
  • channel and video statistics.

How the data is used and stored

  • The data is used only to carry out actions the channel owner starts.
  • The OAuth token and any downloaded data stay on the owner's own computer. They are not uploaded to any server run by the tool.
  • No data is sold, shared with third parties, or used for advertising.
  • The tool collects no data from any other person.

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file also removes the tool's access.

Contact

Questions: use the support email shown on the Google sign-in consent screen for this app.
